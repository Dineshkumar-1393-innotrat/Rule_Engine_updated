1 Executive Summary

The MQTTVirtualDeviceDashboard.jsx is a fully self-contained React 18 component that simulates a connected vehicle TBOX (Telematics Box / Dongle) device communicating over the MQTT protocol with protobuf-encoded messages over the CVIP (Connected Vehicle India Platform). It is embedded inside the Rule Engine Dashboard at /mqtt-virtual-device.

⚡ Key Feature No real MQTT broker is required. All payloads are mock-simulated as structured JSON matching the actual protobuf schema from the source Node.js scripts. The component can be used entirely offline for diagnostic and testing purposes.

Dashboard Capabilities

  • Configure full device identity: VIN, IMEI, TBOX Serial, Broker URL, Protocol Version
  • Simulate MQTT connect / disconnect lifecycle with visual connection state machine
  • Publish 6 categories of MQTT messages: Vehicle Telemetry, Location, Events, Alerts, Trips, Device Join
  • Simulate 8 types of incoming server commands and send back command responses with correlationId
  • View 6 live telemetry gauges with animated spring-count transitions and trend arrows
  • Browse a scrollable, filterable message log with JSON + Hex payload expansion
  • Auto Drive mode — continuous GPS drift + telemetry stream every 3 seconds
  • Export full log as JSON for offline analysis

11 State Management Architecture

Global state is managed via React useReducer with a single normalized state tree consisting of 8 top-level slices:

const initialState = { config: { vin, imei, tboxSerial, clientId, messageId, correlationId, broker, protocolVersion }, connection: { status, publishCount, receiveCount, uptimeSeconds, lastPublishAt, connectedAt }, telemetry: { fuelLevel, engineSpeed, engineWaterTemp, batteryVoltage, odometer, gpsLat, gpsLong ... }, telemetryHistory: { fuelLevel: [...10], engineSpeed: [...10], ... }, // trend arrow computation log: [ { id, timestamp, direction, messageType, topic, status, payloadBytes, ... } ], commandInbox: [ { id, commandType, correlationId, receivedAt, responseStatus } ], toasts: [ { id, message, type } ], activePublishTab: 'vehicleTelemetry', autoDriveActive: false };

Reducer Actions

Action TypeEffect
SET_CONFIGMerges new config values from Device Identity panel
SET_CONNECTIONPartial merge of connection state slice
INCREMENT_PUBLISHpublishCount++, updates lastPublishAt
INCREMENT_RECEIVEreceiveCount++, updates lastReceiveAt
